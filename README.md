# ASHUR-PROTECT MULTI — صانع بوتات الحماية

هذا مشروع أولي لصانع يدير عدة بوتات حماية تيليجرام. ينشئ المستخدم بوتات الحماية بنفسه عبر BotFather، ثم يضيف توكن كل بوت إلى بوت الصانع. لا يمكن للبرنامج إنشاء توكنات تيليجرام من تلقاء نفسه.

## ما الذي يفعله؟
- بوت تحكم رئيسي خاص بالمالك.
- إضافة عدة بوتات حماية عبر `/addbot TOKEN`.
- عرض البوتات عبر `/mybots`.
- إزالة بوت عبر `/removebot BOT_ID`.
- تشفير توكنات البوتات المحفوظة باستخدام مفتاح Fernet.
- تشغيل البوتات المضافة وإعادة تشغيلها بعد عودة الخدمة.
- حماية أولية للمجموعات: حذف الروابط والحد من الرسائل المتتابعة.
- أوامر `/warn` و`/ban` و`/unban` داخل بوت الحماية.

## مهم قبل الاستخدام
1. أنشئ بوت الصانع من `@BotFather` وخذ توكنه.
2. أنشئ كل بوت حماية إضافي من `@BotFather` وخذ توكنه.
3. لا ترفع أي توكن أو ملف `.env` إلى GitHub.
4. اجعل مستودع GitHub خاصاً. أدخل الأسرار فقط في Environment على Render.
5. أضف كل بوت حماية إلى مجموعته واجعله مشرفاً بصلاحيات حذف الرسائل وحظر الأعضاء.
6. استخدم قرصاً دائماً على الاستضافة حتى تبقى قاعدة البيانات بعد إعادة التشغيل. ملف `render.yaml` يطلب قرصاً دائماً؛ توفره وتكلفته يعتمدان على خطة Render الحالية.

## المتغيرات المطلوبة
- `CONTROL_BOT_TOKEN`: توكن بوت الصانع الرئيسي.
- `OWNER_ID`: رقم حساب تيليجرام للمالك (رقم رقمي، وليس اسم المستخدم).
- `FERNET_KEY`: مفتاح تشفير. أنشئه مرة واحدة بالأمر:
  `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`
  احتفظ به سرياً ولا تغيّره بعد إضافة البوتات، وإلا لن يمكن فك تشفير التوكنات المخزنة.

## التشغيل محلياً
```bash
pip install -r requirements.txt
# عيّن المتغيرات الثلاثة في بيئة التشغيل
python -m ashur.main
```

## النشر
ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم اربط المستودع بخدمة Worker على Render. أضف المتغيرات الثلاثة في Environment. لا تضع قيمها في ملفات المشروع.

## حدود النسخة
- هذه نسخة أولية وليست منتجاً تجارياً جاهزاً؛ اختبرها في مجموعة تجريبية أولاً.
- كل البوتات تعمل داخل عملية استضافة واحدة؛ حدود الموارد وعدد الاتصالات تعتمد على خطة الاستضافة.
- الاستضافة المجانية قد تنام أو تتوقف أو لا توفر قرصاً دائماً. إذا لم يتوفر تخزين دائم فقد تفقد قاعدة البيانات عند إعادة النشر.
- لا يوجد حالياً موقع لوحة تحكم، ولا إدارة متقدمة للقنوات أو صلاحيات متعددة المستويات.
- توكنات البوتات أسرار حساسة؛ لا تشاركها في المحادثة ولا مع أي شخص.
